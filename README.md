## How it was made

The video took two generations, both in Claude Code:

1. **First generation** ([`legacy/`](legacy/)): Claude Opus 5.5 (Medium)
2. **Second generation** (everything else): Claude Opus 5.5

**Everything in this repository was generated by the model.** No scene ideas were specified. The only direction was to:

- use the Clawd character design
- give each lyric interesting visuals and transitions

[`ANIMATION_GUIDE.md`](ANIMATION_GUIDE.md) was written by Opus to brief the subagents it ran in parallel.

[`STORYBOARD.md`](STORYBOARD.md) was also written by Opus after the first generation, after being instructed to use P5 brushstrokes, make each scene visually interesting, and make every scene transition into the next.

## Rendering

You need Node.js, Google Chrome and ffmpeg. The song is included at `assets/pdoom.mp3`.

```bash
npm install
node render.mjs --frames=0:156.6 --workers=4   # paint every frame into out/frames (resumable)
node render.mjs --encode --out=out/pdoom.mp4   # join the frames and the song into an MP4
```

The renderer looks for Chrome/Chromium in the usual Windows, macOS and Linux locations. If yours is elsewhere, add `--chrome=<path to chrome>` or set `CHROME_PATH`.

Check your work quickly before a full render (full frames are slow, especially without a GPU):

```bash
node render.mjs --sheet=4,24,80 --cols=3 --out=out/check.jpg   # contact sheet of a few moments
node render.mjs --clip=23:29 --out=out/test.mp4                 # short clip with audio
```

## Making your own

The song, lyric timings (`src/lyrics.js`) and chapter boundaries (`src/timeline.js`) stay the same; the scenes are yours to rewrite.

| Chapter file | Song time | Lyrics |
|---|---|---|
| `c01_lab.js` | 0–23 s | Curtain up, "I see sparks of AGI…" → "ChatGPT, please don't eat me alive" |
| `c02_chorus1.js` | 23–38.5 s | Chorus 1: "…'cause the future goes FOOM" |
| `c03_takeoff.js` | 38.5–59 s | "We had a stable training run…" → "Sydney, please let me free" |
| `c04_chorus2.js` | 59–73 s | Chorus 2: basilisk, NVDA, 1e30 FLOPs |
| `c05_obsolete.js` | 73–95.4 s | "Forward MLP, backward, repeat…" → "Gato, please don't let me go" |
| `c06_chorus3.js` | 95.4–109.4 s | Chorus 3: paperclips, killswitch guys on PTO |
| `c07_scale.js` | 109.4–123.5 s | "Just transformers all the way!" → "RLHF goes askew" |
| `c08_chorus4.js` | 123.5–140.5 s | Chorus 4: Loom, recursive self-upgrade, "What did Ilya see?", "Was it all for show?" |
| `c09_finale.js` | 140.5–156.6 s | Curtain call |

Each chapter calls `chapter(name, start, end, [[t0, shotFn], ...])`; a shot function paints the whole frame as a pure function of song time. Read [`ANIMATION_GUIDE.md`](ANIMATION_GUIDE.md) for the painting API, Clawd/cast helpers and rules (no `Math.random()`, keep action above the karaoke bar), and rewrite [`STORYBOARD.md`](STORYBOARD.md) with your own shot list first — it's the easiest way to brief Claude on new scenes.
